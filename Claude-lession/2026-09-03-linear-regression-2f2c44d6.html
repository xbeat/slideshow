1 Định nghĩa ngắn gọn

Linear Regression (Hồi quy tuyến tính) là thuật toán supervised learning để dự đoán một giá trị số liên tục (y) từ một hoặc nhiều đặc trưng đầu vào (x), bằng cách giả định quan hệ giữa chúng gần như một đường thẳng: ŷ = w·x + b. Việc "học" chính là đi tìm w (hệ số góc) và b (hệ số chặn) sao cho đường thẳng đó khớp nhất với dữ liệu thật — tức là tổng bình phương sai số nhỏ nhất (Ordinary Least Squares).

Dữ liệu (x, y): x = Diện tích (m²), y = Giá nhà (triệu VNĐ) │ Giả thuyết (hypothesis): ŷ = w·x + b ← đường thẳng cần tìm │ Hàm mất mát (Cost function): MSE = (1/n) · Σ (yᵢ - ŷᵢ)² │ Tối ưu hoá: tìm w*, b* sao cho MSE nhỏ nhất ┌─────────────────┴─────────────────┐ Normal Equation (closed-form) Gradient Descent (lặp dần) w = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)² w ← w - η · ∂MSE/∂w (mỗi epoch) b = ȳ - w·x̄ b ← b - η · ∂MSE/∂b (lặp nhiều epoch) └─────────────────┬─────────────────┘ ŷ = w*·x + b* ← đường thẳng "khớp" nhất với dữ liệu

Chọn sai learning rate (η) hoặc dừng Gradient Descent quá sớm sẽ khiến w, b không bao giờ tới được điểm tối ưu — đây chính là thứ ta sẽ "vặn tay" trong phần Demo bên dưới.

3 4 trạng thái khi huấn luyện Linear Regression trên cùng bộ dữ liệu

Cùng 12 căn nhà trên, chỉ đổi cách tìm w, b — xem sai số (MSE) và R² thay đổi ra sao:

❌ Trạng thái 1 — Baseline: chỉ đoán giá trung bình ❌ Xấu

Không học w, b nào cả — luôn dự đoán ŷ = ȳ = 950.42 triệu, BẤT KỂ diện tích bao nhiêu Nhà 30 m² → dự đoán 950.42 triệu (thực tế 480) Nhà 100 m² → dự đoán 950.42 triệu (thực tế 1565) MSE = 102,122.74 R² = 0.0000 ← "mức sàn": mô hình không dùng thông tin Diện tích chút nào
y_pred = np.full_like(y, y.mean())     # "mô hình" chỉ đoán trung bình, bỏ qua X
mean_squared_error(y, y_pred)          # 102122.74
r2_score(y, y_pred)                    # 0.0 — theo định nghĩa, baseline trung bình luôn có R²=0

Đây là điểm xuất phát để so sánh: nếu một mô hình "học" ra mà vẫn không tốt hơn baseline này, nó vô dụng.

❌ Trạng thái 2 — Gradient Descent, learning rate quá lớn (phân kỳ) ❌ Xấu

η = 0.001 — quá lớn so với thang đo dữ liệu Diện tích (30-100) Epoch 1: w ≈ 1806 Epoch 5: w ≈ -1,209,354 Epoch 8: w ≈ -100,108,683 (!!) Loss KHÔNG giảm dần mà TĂNG VỌT qua từng epoch → mỗi bước "nhảy" quá xa, vượt qua đáy hàm mất mát MSE, w, b → phân kỳ (diverge), tiến tới vô cùng thay vì hội tụ
w, b = 0.0, 0.0
lr = 0.001                              # quá lớn cho scale dữ liệu này!
for epoch in range(8):
    y_pred = w*X + b
    dw = (2/n) * np.sum((y_pred - y) * X)
    db = (2/n) * np.sum(y_pred - y)
    w -= lr * dw; b -= lr * db
# w ≈ -100,108,683 — hệ số "nổ tung", mô hình hoàn toàn vô dụng

Learning rate không phải "càng lớn càng học nhanh" — quá lớn thì thuật toán bị "văng" ra khỏi vùng hội tụ ngay từ vài bước đầu.

⚠️ Trạng thái 3 — Gradient Descent dừng quá sớm (1 epoch) ⚠️ Trung bình

η = 0.0001 (hợp lý) nhưng chỉ chạy ĐÚNG 1 epoch rồi dừng w ≈ 12.75, b ≈ 0.19 so với nghiệm tối ưu w* ≈ 15.18, b* ≈ 39.38 MSE = 37,312.16 R² = 0.6346 ← khá hơn baseline nhiều, nhưng còn xa mức tối ưu (R²=0.9971)
w, b = 0.0, 0.0
lr = 0.0001
for epoch in range(1):                  # chỉ 1 epoch — dừng quá sớm!
    y_pred = w*X + b
    dw = (2/n) * np.sum((y_pred - y) * X)
    db = (2/n) * np.sum(y_pred - y)
    w -= lr * dw; b -= lr * db
# w=12.75, b=0.19 — đúng hướng nhưng CHƯA kịp hội tụ

Learning rate đúng không có nghĩa là xong — Gradient Descent cần đủ số epoch để w, b thực sự "đi" tới điểm tối ưu.

✅ Trạng thái 4 — Normal Equation / Gradient Descent hội tụ đủ ✅ Tốt

Normal Equation (closed-form) — giải trực tiếp công thức toán, không cần chọn learning rate hay epoch w* = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)² = 15.18 b* = ȳ - w*·x̄ = 39.38 MSE = 295.30 R² = 0.9971 ← gần như khớp hoàn hảo với xu hướng tuyến tính của dữ liệu
from sklearn.linear_model import LinearRegression
model = LinearRegression().fit(X.reshape(-1,1), y)
model.coef_, model.intercept_          # [15.18], 39.38
r2_score(y, model.predict(X.reshape(-1,1)))   # 0.9971

Đây mới là Linear Regression "đúng chuẩn": dùng Normal Equation (khi dữ liệu nhỏ) hoặc Gradient Descent với learning rate hợp lý và đủ epoch để hội tụ về đúng nghiệm tối ưu.

6 Dữ liệu tốt vs dữ liệu xấu

✅ Dữ liệu tốt
  • Quan hệ giữa x và y thực sự gần tuyến tính — scatter plot cho thấy các điểm nằm gần một đường thẳng
  • Không có outlier cực đoan (VD: 1 căn 40 m² nhưng giá 5000 triệu vì vị trí đặc biệt) làm lệch cả đường hồi quy
  • Feature được chuẩn hoá/scale trước khi dùng Gradient Descent — giúp hội tụ ổn định, không cần learning rate siêu nhỏ
  • Khi có nhiều feature: các feature không tương quan quá mạnh với nhau (tránh multicollinearity khiến w không ổn định)
❌ Dữ liệu xấu
  • Outlier cực đoan kéo lệch cả đường hồi quy, vì OLS tối thiểu hoá bình phương sai số — 1 điểm lệch xa đóng góp sai số rất lớn
  • Quan hệ x, y thực chất phi tuyến (dạng cong) nhưng vẫn ép dùng đường thẳng → residual có pattern rõ ràng, mô hình sai hệ thống
  • Dùng nhiều feature trùng lặp thông tin (VD: vừa "diện tích m²" vừa "diện tích ft²") → multicollinearity, hệ số w không đáng tin cậy
  • Không chuẩn hoá dữ liệu khi Gradient Descent chạy trên nhiều feature có thang đo khác nhau → hội tụ rất chậm hoặc phân kỳ
